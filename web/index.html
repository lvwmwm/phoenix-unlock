Phoenix Unlock

Patches Discord's new native client (Phoenix) so it opens without the access gate. It all runs in this browser; nothing is uploaded.

Plugins

Include

Your plugins run next to the ones above (the global phoenix API, plain scripts; types in phoenix.d.ts). Leading // @description, // @version and // @author lines describe it in Discord Settings → Phoenix; a file is named after itself. Optional: pick .js files and/or write one below.

Frida scripts run inside Discord when it starts (Frida 17 API with Java, plain scripts without imports). The ones you pick here are installed on first start; in the app, the floating JS button opens a panel to turn plugins on and off, add more from a URL, reload them, and see their console.

    Download patched APK
    
      1. It installs as Discord Phoenix, next to your normal Discord, and you sign in once.1. Uninstall Discord first if it came from the Play Store; Android won't update an app signed with a different key.
      
    2. Open the downloaded file and allow your browser to install apps if asked.
      
    3. Later builds: just patch again. Builds are signed with Phoenix Unlock's key, rotated from the one earlier builds used, so it installs as an update over either (Android 9+) and you stay logged in.
      
  
      
  
      

  
      
    
      
      
      iOS build (Discord 357.0 / 1.12.2). Pick a decrypted IPA of the hybrid Discord build that contains PhoenixFatClient.framework. App Store copies are FairPlay-encrypted and cannot be patched; decrypt yours first (e.g. with TrollDecrypt on a jailbroken device). The file never leaves your browser.
      
      
      The patch also enables Discord experiments (staff mode) by forcing isStaffEnv in the JS bundle, so the Phoenix launch switch is available without any extra tweak.
      
      
      
      Leave it empty to use the built-in Discord 357.0 decrypted hybrid IPA.
